# صدى | SADA

عرض تقديمي تفاعلي لمنصة **صدى** — منصة وكلاء ذكية تحوّل بيانات الجمهور من منصات هيئة الإذاعة والتلفزيون إلى قرارات محتوى.

فريق **أوج | AWJ**: هاجر الظفيري · شهد بوصالح · رفا الشريف · دالين مليباري

## التشغيل
افتحي `index.html` في المتصفح مباشرة، أو شغّلي خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتحي http://localhost:8000
```

## التحكم بالعرض
- `←` / مسافة / PageDown: التالي · `→` / PageUp: السابق
- `R` إعادة حركة المشهد · `F` ملء الشاشة · `T` المؤقت · `N` ملاحظات المتحدثة · `M` تقليل الحركة
- `Home` البداية · `End` الخاتمة · `?` المساعدة

## الملفات
| المسار | الوصف |
|---|---|
| `index.html` | المشاهد كلها |
| `styles.css` | التنسيق |
| `app.js` | منطق العرض والحركات |
| `data/best_times.js` | بيانات خريطة أفضل أوقات النشر |
| `assets/` | الخطوط والشعارات ولقطات التطبيق |

> ملاحظة: شعار الفريق `assets/logos/awj.png` غير موجود حاليًا — أضيفيه ويظهر تلقائيًا في الخاتمة.
